# C4 Simulator | Tactical Device for Paintball & Airsoft

Este projeto é um simulador de dispositivo C4 desenvolvido para elevar a imersão em jogos de Paintball e Airsoft. A aplicação funciona como um cronómetro tático interativo, simulando o armamento e a detonação de um artefacto em ambiente de jogo.

**Link de Acesso:** [Visualizar Simulador](https://samuel123d.github.io/c4)

---

## Resumo do Projeto

O simulador foi criado para servir como um objetivo central em missões táticas. Através de uma interface que remete a equipamentos militares, os jogadores podem interagir com o "dispositivo" para cumprir objetivos de armar ou desarmar, incluindo efeitos sonoros para máxima imersão.

### Tecnologias e Ferramentas

| Categoria | Tecnologias Utilizadas |
| :--- | :--- |
| **Frontend** | HTML5, CSS3 |
| **Lógica** | JavaScript (Timers e Eventos) |
| **Áudio** | Web Audio API (Integração de `explosao.mp3`) |
| **Hosting** | GitHub Pages |

---

## Estrutura de Diretórios

A estrutura é minimalista e eficiente para garantir um carregamento rápido em dispositivos móveis durante os jogos:

* **index.html**: Interface principal com o visor do cronómetro e botões de interação.
* **explosao.mp3**: Ficheiro de áudio acionado ao final da contagem decrescente.
* **README.md**: Documentação do projeto.

---

## Funcionalidades Táticas

O projeto demonstra a aplicação de lógica de programação em cenários recreativos reais:

> **Imersão Audiovisual**
> O sistema utiliza contagens decrescentes precisas sincronizadas com alertas sonoros, permitindo que as equipas utilizem o smartphone ou tablet como um acessório real de jogo no terreno.

---

## Instalação e Utilização no Terreno

Para utilizar o simulador no seu jogo:

1. Aceda ao link oficial via navegador no telemóvel.
2. Defina o tempo de contagem (se configurável) ou inicie o armamento.
3. Coloque o dispositivo num local seguro e estratégico do campo de jogo.
